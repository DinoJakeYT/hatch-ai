Checking this PC's tools…
raylib (3D game library)

An easy C++ library for 3D and 2D games (cubes, models, cameras, sound) that AIs know well. Optional: without it, 3D games use OpenGL, which is built into Windows. Downloads the official build from github.com/raysan5/raylib (about 2.5 MB).

Seeing screenshots

When a local model previews what it built, models that can see images get the screenshot itself. For the rest, this vision model looks at it and describes it in words, and Hatch adds measured facts (size, main colors, blank or not). Small vision models like moondream are rough; for sharper descriptions install a bigger one, e.g. ollama pull qwen2.5vl or ollama pull gemma3:4b.

Skills

Skills are folders of instructions (sometimes with scripts) that teach an AI how to do something, in the SKILL.md format Claude, ChatGPT (Codex) and Gemini share. Hatch gives your skills to every AI, local models included. Only import skills from people you trust: the AI will follow them.

Guides for local models

Step-by-step methods local models follow, the way stronger AIs work: plan, build in small steps, test, fix the real error, then finish. "general" is always used; the others are picked by the keywords on their first line (for example C++ for "make a C++ game").

Teams

A team is a lead AI plus helper AIs it can hand work to. The lead plans and checks; helpers do the hands-on coding, building and testing. Give the heavy work to a local model or a cheaper AI to save usage on the important one. Pick a team from the AI menu at the top of a chat.

Claude (subscription, API key, OpenRouter, custom), ChatGPT/OpenAI and local models can lead. Any AI can be a helper. Helpers work one at a time in the chat's project folder, and each keeps its own memory of the chat.

Phone

Use Hatch from your phone's browser: watch chats live, start new ones, send messages (even while an AI works), approve steps, stop and undo. Your PC does the work, so keep Hatch open.

  1. Connect your phone to the same Wi-Fi as this PC.
  2. Scan the code with your phone's camera and open the link.
  3. Optional: use "Add to Home Screen" in the phone's browser to get a Hatch app icon.
Away from home

Install Tailscale (free) on this PC and on your phone, and sign in to both with the same account. A second code then shows up here that works from anywhere, privately and encrypted. Hatch is never put on the open internet.

Anyone with this code can use Hatch on this PC, so don't share it or show it in videos. If one gets out, press "Disconnect all phones" for a new code. The first time you turn this on, Windows asks whether Hatch may use the network: allow it on private networks.

Hatch

Free and open source under the GPL-3.0 license. Source code, releases and issues on GitHub

Updates

Hatch checks GitHub for a new version every few hours, downloads it in the background, and installs it when you restart Hatch (or the next time you close it). Your chats, settings and projects stay as they are.

Permissions

What new chats may do without asking. Each chat can change it from the shield button at the top.

Display

Instructions

Given to every AI in every chat, like a shared rule book.

Memory

Facts the AIs remember between chats. They read it (it's included when short) and add a line when they learn something worth keeping.

Usage & limits

Monthly budgets

For pay-as-you-go keys. Hatch counts Claude API spend itself and reads OpenRouter's own numbers.

Work overnight

  • It plans, builds, tests and fixes on its own, then keeps improving, all inside this chat's project folder, without asking.
  • It saves a checkpoint (with git) after every working build. In the morning the project is at its last working version.
  • Hatch keeps your PC awake. Leave Hatch open (minimizing is fine).
  • You get a report and a notification when it's done.

New skill

Every AI in Hatch gets your skills in new chats and uses one when its description fits the task. Keep it focused: one kind of job per skill.
